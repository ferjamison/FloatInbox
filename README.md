# 浮笺 · Windows 悬浮收件箱（MVP 0.1）

## 第一次运行

1. 在自己的 Windows 10/11 64 位电脑上将整个 ZIP 解压。双击 Setup-D.cmd。需要可写的 D 盘，首次会从 Electron 官方 GitHub 下载 Windows 运行环境并校验 SHA-256，无需 Node.js 或管理员权限。
2. 项目、源码和原件都放在 D:\Projects\FloatInbox。桌面出现 FloatInbox 快捷方式。以后用快捷方式或 Start.cmd 打开。默认在登录 Windows 后启动，设置里可以关闭。
3. 点「微信接收」，用手机微信扫码。按手机显示的网页版会话发送素材。微信决定会话的有效期。
4. 在接收页对附件点微信提供的下载/接收操作。下载完成时才归档。对于照片，可以打开大图后右键「收存这张网页图片」；该操作保存的是网页实际提供的图片版本，要保留手机原始文件请在发送端按文件发送并下载。对选中的文字或链接右键也可收存。
5. 点「历史记录 → 图片 → 复制图片」，回到 PPT 粘贴。点窗口右上角 › 收起，从桌面边缘点「浮笺」展开。同一张图下次开机仍可复制或另存。

如果微信页因网络或微信授权策略无法连接，可用「收存 → 从电脑选择文件」导入已经下载的原件，或「从剪贴板收存」保存当前文字和图片。剪贴板图像保存为 PNG。无法解码的图片仍可另存原文件。

## 历史和边界

只有已收存的项目进入历史。官方网页中仅显示的消息不会被批量镜像；关机期间的微信消息能否在下次登录时补收取决于微信。微信接收与本地历史在不同页面中运行。只向本地历史界面开放读档案、写剪贴板的权限。

data/originals 保存接收到的附件字节，data/history.sqlite 保存时间、文件名、文本与路径。搜索匹配文件名或文字、网址原文，不含图片文字识别。首次加载网络、登录失效和没有微信登录的情况下仍可查看本机历史。微信页面自身的登录数据由 Electron 在当前 Windows 用户的 AppData 下管理。退出应用后备份整个 data 文件夹可保留完整历史，删除整个项目目录前请先备份。

## 下载困难时

如果电脑访问 GitHub 慢，可以在可访问官方发布页的设备下载适合 Windows 架构的运行包及同一页的 SHASUMS256.txt，放在解压后 Setup-D.cmd 的同一层，再双击安装。运行包名称为 electron-v45.5.0-win32-x64.zip 或 electron-v45.5.0-win32-arm64.zip。
https://github.com/electron/electron/releases/tag/v45.5.0

脚本只在目标不存在时复制源码。若已存在本项目则复用，不覆盖开发中的代码和历史。可在设置中关闭自启动后退出，再删除快捷方式。无需清理系统组件。

## 继续开发

- app/main.cjs — 悬浮窗、微信接收视图、下载完成事件、Windows 剪贴板。
- app/archive.cjs — SQLite 索引、附件落盘、搜索、分页。
- app/index.html、app/style.css、app/ui.js — 悬浮窗界面及交互。
- app/preload.cjs — 历史页调用的桌面操作。
- scripts/Install.ps1 — D 盘项目初始化与运行环境安装。
- test/ — 存储与重启回归、模拟官方下载完成事件与本地权限验证。使用 Node 24 运行 npm test。

真机验收可用同一张图片依次完成：扫码发送、接收归档、粘贴入 PowerPoint、退出再启动、离线再次复制。再测试视频下载中断不入库，并在登录 Windows 后确认悬浮窗随系统出现。
